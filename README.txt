NearNeed Public Site

This folder is ready for static website hosting.

Fastest publish option:
1. Go to Netlify Drop: https://app.netlify.com/drop
2. Drag the entire NearNeed_PublicSite folder into the drop area.
3. Netlify will generate a public .netlify.app URL.
4. Make sure the project's visibility is Public before sharing it with your professor.

The website entry point is index.html.
